Sua leitura, do seu jeito

Mais conforto para ler.

Escolha o tema, as cores e o tamanho do texto para uma leitura confortável. Suas preferências ficam salvas neste navegador quando o armazenamento está disponível e valem para todas as páginas do site.

Você também pode usar o zoom do próprio navegador. No computador, experimente Ctrl + + para ampliar e Ctrl + 0 para restaurar.

Para usar os controles desta página, habilite o JavaScript. O zoom e as preferências do navegador continuam disponíveis.

Recursos do site

Pequenos cuidados. Menos barreiras.

  • 01

    Navegação por teclado

    Links, botões e campos podem ser alcançados com Tab. Um contorno destaca o item em foco para ajudar você a se localizar.

  • 02

    Um atalho para o conteúdo

    O primeiro link da página aparece ao receber foco e permite pular o menu, levando você diretamente ao conteúdo principal.

  • 03

    Imagens com contexto

    As imagens informativas têm descrições alternativas, e a galeria apresenta legendas para deixar claro o contexto de cada imagem.

  • 04

    Formulários identificados

    Cada campo possui um rótulo. O navegador indica campos obrigatórios e verifica o formato do e-mail antes de enviar a ficha.

  • 05

    Leitura em voz alta

    Ative a leitura para ouvir os trechos ao passar o mouse ou navegar com o teclado, com escolha de voz e velocidade.

  • 06

    Respeito ao seu ritmo

    O layout se adapta a diferentes telas. As animações são reduzidas quando a preferência por menos movimento está ativada no seu dispositivo.

Guia rápido

Explore sem o mouse.

Use os comandos do teclado para percorrer o conteúdo. Os mesmos links estão disponíveis no menu e no rodapé.

Comandos básicos de navegação
TeclaO que faz
TabVai para o próximo link, botão ou campo.
Shift + TabVolta para o item anterior.
EnterAbre o link ou ativa o controle selecionado.
EspaçoAtiva um botão ou marca uma opção.
← →Troca a imagem na ampliação da galeria.
EscFecha a ampliação da galeria e interrompe a leitura em voz alta.

Um compromisso contínuo

Acessibilidade se constrói com escuta.

A acessibilidade do site está em melhoria contínua. Testes com tecnologias assistivas e sugestões das pessoas usuárias ajudam a identificar ajustes.
